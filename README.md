# Crimson Octopus, Impossible Escape

A vivid crimson octopus bursts out of a small glass bottle resting on a coral reef, its eight tentacles unfurling in every direction like a genie rising from a lamp, its eyes locked straight on the viewer. The impossible escape is the whole thrill: a creature far too big for its tiny bottle, slipping free anyway, and staring you down as if daring you to explain how it got out.

## How to run

Run `node main.ts`. It copies `entry.png` atomically to the directory given by `MAKEFUN_OUTPUT_DIR`, or `/output` when that variable is not set.
